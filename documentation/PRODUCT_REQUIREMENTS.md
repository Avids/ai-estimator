# Product requirements
Purpose: contractor estimating for commercial electrical work, not consultant design. Inputs: multi-page PDF drawing packages, specifications, addenda, revisions and related architectural/mechanical drawings. Outputs: traceable device quantities, editable drawing annotations, estimating-only routes, conductor/conduit quantities, exception reports, annotated PDF and Excel.

Mandatory: immutable originals; unique page IDs; source-backed project rules (minimum/maximum conduit and conductor sizes, Cu/Al, insulation, raceway types, applicability); counts tied to visible marks; review and correction; source/circuit confirmation before routing; no invented assignments; explicit scale, drops and entry points; revision and duplicate-detail control; local-first data handling.

User workflow: create project > upload > split and classify > approve rulebook and scales > detect/count > review > map circuits > route > edit > recalculate > export. Approve rules and unresolved assumptions separately. Support fire alarm, communications and security later with separate rules.
