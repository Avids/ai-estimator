# Architecture
Qt/PySide6 desktop UI calls deterministic Python services; SQLite authoritative data; original and split PDFs stored locally. PyMuPDF extraction/render/export. Future OpenCV/vector matching and YOLO detector; NetworkX circuit graph; Shapely geometry; A* and OR-Tools optimization. Optional structured AI extraction with explicit authorization; optional MCP adapter only after supported connection verified. Keep UI independent of algorithm modules. All computations must be reproducible from saved inputs and rules. Evaluate licenses, including model weights, before deployment.
