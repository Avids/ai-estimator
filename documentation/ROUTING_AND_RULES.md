# Routing and specification rules (planned)
Extract rules with precise source clause, document revision, quote, scope, normalized value and units. Distinguish mandatory code, contract, equipment and assumptions; flag conflicts, do not silently resolve precedence. Missing or unapproved sizing inputs block final quantities. No generic copper/aluminum defaults.
Build a calibrated graph of permitted regions and obstacles, with costs for bends, penetrations and access. Route confirmed circuits from load to source using A*; optimize shared segments only when compatibility, fill, derating and other constraints are validated. Count each physical raceway once and every conductor traversal separately. Distinguish horizontal lengths, drops, termination allowances and waste. Flag missing top/bottom entry, risers and ceiling data. Outputs are estimating proposals, not approved installation drawings.
